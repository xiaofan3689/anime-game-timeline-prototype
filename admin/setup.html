管理员配置指南

第一次部署

  1. 把 admin 和 functions 文件夹覆盖到 GitHub 仓库根目录。保留 data/manual.json 和 data/reminders-sent.json。
  2. Cloudflare 的 Workers 和 Pages → 网站项目 → 设置 → 变量和机密 → 生产环境，添加下表配置。
  3. Zero Trust → 访问 → 应用程序，建立同一个自托管应用，保护 admin、admin/*、api/admin/* 路径，允许指定邮箱通过一次性验证码登录。
  4. 保存配置后重新部署 Pages。打开管理后台，点击重新连接。
变量填写内容
ACCESS_TEAM_DOMAINhttps://你的团队.cloudflareaccess.com
ACCESS_AUDAccess 应用的受众标识
ADMIN_EMAIL策略允许的管理员邮箱
GH_OWNERGitHub 仓库所属账号
GH_REPO仓库名称，不带网址
GH_BRANCH通常 main
GH_TOKEN加密机密；只授权目标仓库，Contents 内容权限为读取和写入

以后升级

只覆盖升级包里的 admin 和 functions 文件夹即可。现有环境变量和 Access 配置可以继续使用，无需重复创建。后台编辑完成后先保存到草稿，再提交到 GitHub；发布仍需等待同步任务与 Pages 部署。

排错

令牌权限不足：检查令牌授权的仓库与 Contents 权限。403 身份验证失败：核对团队地址、AUD 与管理员邮箱。404：核对仓库名称、分支和 Functions 是否部署。修改机密后必须重新部署。
